Privacy policy

Last updated: 2026-11-09

Who uses this app. estudio-canais is a personal tool used only by its developer, on YouTube channels the developer owns. It has no other users.

What data it accesses. With the channel owner's consent, through Google OAuth, it reads YouTube channel and video information and analytics reports: views, watch time, audience retention, traffic sources, subscribers, impressions, click-through rate and estimated revenue. Scopes used: youtube.readonly, yt-analytics.readonly and yt-analytics-monetary.readonly.

How the data is used. Only to analyze the performance of the developer's own channels. The data is stored on the developer's own computer.

Sharing. The data is not sold, shared with third parties, or used for advertising.

Retention and deletion. Data is kept only as long as needed for this analysis. Access can be revoked at any time at myaccount.google.com/permissions, after which the stored tokens stop working.

Google API Services. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Contact. Use the support email shown on the Google consent screen of this app.
